# QA 测试用例设计技能

> 项目「已配置的 qa-skill-suite / lynxce-test-cases 技能」镜像封装。

## 适用
- 从 PRD / 原型 / User Story / 已有用例 抽取测试点并生成结构化用例。
- 用例评审要点：覆盖（功能/边界/异常）、可追溯（用例↔需求）、可执行、无歧义。

## 方法速查
| 方法 | 何时用 | 产出 |
|---|---|---|
| 等价类划分 | 输入域大、可分类 | 有效/无效等价类 |
| 边界值分析 | 数值/长度/分页 | 上点/离点/内点 |
| 场景法 | 主流程+分支 | 场景列表+用例 |
| 判定表 | 多条件组合 | 条件组合矩阵 |

## 与本项目对接
- 用例字段遵循 `agent-skills/requirements-to-cases/SKILL.md` 规范（id/标题/类型/优先级/前置/步骤/预期/可自动化）。
- 产物可落 `extensions/requirements_to_cases/cases.md` 或直接转 `test_*.py`。
