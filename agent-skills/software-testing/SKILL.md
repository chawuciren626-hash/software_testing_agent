# 软件测试（全流程）技能

> 本 SKILL 是项目「已配置的 software-testing 技能」在智能体侧的镜像封装，
> 让 `agentic-test-explorer` 的 `fetch_agent_skill` 能直接加载这套方法论。

## 核心知识域
- **测试基础**：用语（缺陷/用例/冒烟/回归）、测试原则、质量模型（ISO 25010）。
- **用例设计**：等价类划分、边界值分析、场景法、判定表、正交法。
- **缺陷管理**：缺陷生命周期、严重/优先级、缺陷报告要素。
- **测试过程**：单元/集成/系统/验收；准入准出；敏捷中的测试角色。
- **专项测试**：性能（负载/压力/并发）、安全（鉴权/注入/越权）、自动化（单元/UI/接口）。

## 用法约定
- 探索智能体在 `plan` / `confirm` 阶段用本技能校验用例覆盖是否充分。
- 与 `requirements-to-cases`、`api-test-design`、`web-automation` 技能配合使用。

## 产出
- 测试计划、测试用例、缺陷报告、专项测试方案（见 extensions/ 各模块）。
